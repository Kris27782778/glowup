## 一、申訴／檢舉系統

### 功能說明

使用者可對產品、問答、社群回答送出檢舉，管理員在後台可收到並處理。

### 涉及檔案

| 檔案 | 角色 |
|------|------|
| `backend/routes/reports.js` | 新建。`POST /api/reports` 處理檢舉送出，內含重複檢舉防護（同使用者、同目標、pending 狀態）回傳 409 |
| `backend/index.js` | 掛載 `/api/reports` 路由 |
| `frontend/src/components/ReportModal.js` | 新建。通用檢舉 Modal，5 種原因選項，選「其他」顯示說明欄 |
| `frontend/src/ProductDB.js` | 產品卡片加入檢舉按鈕（hover 才顯示，frosted glass 樣式） |
| `frontend/src/QA.js` | 問題卡片與社群回答均加入檢舉按鈕 |

### 資料表（需在 Supabase 執行）

```sql
CREATE TABLE reports (
  report_id   SERIAL PRIMARY KEY,
  reporter_id INTEGER REFERENCES users(user_id),
  target_type TEXT NOT NULL,   -- 'product' | 'question' | 'answer'
  target_id   INTEGER NOT NULL,
  reason      TEXT NOT NULL,
  description TEXT,
  status      TEXT NOT NULL DEFAULT 'pending',
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

## 三、年度重驗機制

### 功能說明

帳號每 365 天需重新驗證輔大信箱，確保僅在校生可使用。到期前 30 天顯示警告橫幅，到期後強制重驗才能登入。

### 運作流程

```
登入
 └─ 密碼正確
     ├─ last_verified_at 超過 365 天 → HTTP 403 REVERIFY_REQUIRED
     │    └─ 前端導向 /reverify → 發送 OTP → 輸入驗證碼 → 更新 last_verified_at
     ├─ 剩餘 ≤ 30 天 → HTTP 200 帶 warning.daysLeft
     │    └─ 登入成功，Dashboard 顯示黃色/紅色警告橫幅
     └─ 一般情況 → HTTP 200 正常登入
```

### 涉及檔案

| 檔案 | 改動 |
|------|------|
| `backend/routes/auth.js` | 登入加入年度到期判斷；新增 `POST /api/auth/reverify`（OTP 驗證 + 更新 `last_verified_at`） |
| `frontend/src/Reverify.js` | 新建。兩步驟頁面：發送 OTP → 輸入驗證碼 → 重導首頁 |
| `frontend/src/Login.js` | 捕捉 403 `REVERIFY_REQUIRED`，導向 `/reverify` |
| `frontend/src/Dashboard.js` | 計算 `verifyDaysLeft`，≤ 30 天顯示固定警告橫幅 |
| `frontend/src/App.js` | 新增 `/reverify` 路由 |

### 資料表異動（需執行）

```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS last_verified_at TIMESTAMPTZ;
UPDATE users SET last_verified_at = NOW() WHERE last_verified_at IS NULL;
```

## 四、產品資料庫導覽功能

### 功能說明

初次使用者看到空白頁面時顯示視覺化引導；加入動態 Spotlight 步驟教學。

### 空白狀態 Onboarding

三個圓形步驟圖示（選擇領域 → 設定篩選 → 查看推薦），箭頭連接，「開始引導 →」啟動 Spotlight 教學。

### Spotlight 教學（TourOverlay）

```
步驟 0：選擇探索領域（filterSection ref）
步驟 1：設定篩選條件（aside sidebar ref）
步驟 2：查看推薦清單（main results ref）
```

實作方式：`getBoundingClientRect()` 取得元件位置，`box-shadow: 0 0 0 9999px rgba(...)` 製造半透明遮罩挖洞效果，350ms 過渡動畫。

### 涉及檔案

| 檔案 | 改動 |
|------|------|
| `frontend/src/ProductDB.js` | `tourStep` state、`tourRefs` useRef、`TourOverlay` 子元件、空白 Onboarding UI |

## 六、忘記密碼

### 功能說明

在登入頁提供「忘記密碼？」連結，引導三步驟重設：輸入帳號 → OTP 驗證 → 設定新密碼。

### 流程

```
/forgot-password
  Step 1：輸入帳號（@ 前段）→ POST /api/auth/send-verification
  Step 2：輸入 6 位 OTP → POST /api/auth/verify-otp
  Step 3：輸入新密碼 × 2 → POST /api/auth/reset-password
完成後導回 /login 並顯示「密碼已重設成功」綠色提示
```

### 涉及檔案

| 檔案 | 改動 |
|------|------|
| `backend/routes/auth.js` | 新增 `POST /api/auth/reset-password`：確認 `email_verifications.verified_at` 在 30 分鐘內，bcrypt hash 新密碼後寫入 DB |
| `frontend/src/ForgotPassword.js` | 新建。3 步驟頁面，左側品牌區 + 右側表單，支援 OTP paste |
| `frontend/src/App.js` | 新增 `/forgot-password` 路由 |
| `frontend/src/Login.js` | 加「忘記密碼？」連結；讀 `location.state.resetSuccess` 顯示成功提示 |

## 八、卡片點擊導航

### 功能說明

個人儀表板各 Tab 的卡片可直接點擊跳轉至對應模組，並自動定位到該內容。

### 對應關係

| 儀表板 Tab | 點擊行為 | 目標 |
|-----------|---------|------|
| 收藏（Tab 2） | 點產品卡片 | `/products` + 自動開啟 ProductPopover |
| 歷史評論（Tab 4） | 點評論卡片 | `/products` + 自動開啟 ProductPopover |
| 問答（Tab 1） | 點問題卡片 | `/qa` + 自動展開該問題，切換至「我的提問」Tab |

### 實作細節

- Dashboard → 傳遞 `navigate('/products', { state: { openProduct: p } })`
- ProductDB → `useEffect` 讀取 `location.state.openProduct`，直接 `setSelectedProduct`
- QA → `useEffect` 讀取 `location.state.expandId`，設 `expandedId` 並切換 tab
- 所有卡片內的刪除、取消收藏按鈕加 `e.stopPropagation()` 防止誤觸

### 涉及檔案

`frontend/src/Dashboard.js`、`frontend/src/ProductDB.js`、`frontend/src/QA.js`

## 附錄：API 端點總覽

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/auth/send-verification` | 寄送 OTP 驗證碼（60 秒冷卻） |
| POST | `/api/auth/verify-otp` | 驗證 OTP（最多 3 次） |
| POST | `/api/auth/register` | 註冊（需先完成 OTP 驗證） |
| POST | `/api/auth/login` | 登入（含年度驗證到期判斷） |
| PATCH | `/api/auth/profile` | 更新暱稱／簡介／膚質 |
| PATCH | `/api/auth/password` | 更改密碼（需舊密碼驗證） |
| POST | `/api/auth/reset-password` | 忘記密碼重設（需 OTP 已驗證） |
| POST | `/api/auth/reverify` | 年度重驗（OTP 驗證 + 更新 `last_verified_at`） |
| GET | `/api/products` | 取得產品列表（支援 category / skin_type / effect / finish / coverage / search / sort / page） |
| GET | `/api/reviews/:product_id` | 取得產品評論 |
| GET | `/api/reviews/user/:user_id` | 取得使用者歷史評論 |
| POST | `/api/reviews` | 新增／更新評論（UPSERT） |
| DELETE | `/api/reviews/:review_id` | 刪除評論（驗證所有權） |
| GET | `/api/wishlist/:user_id` | 取得收藏清單（含產品資料） |
| POST | `/api/wishlist` | 新增收藏（防重複） |
| DELETE | `/api/wishlist` | 取消收藏 |
| GET | `/api/questions` | 取得問題列表（支援 tag / search / solved / user_id / page） |
| POST | `/api/questions` | 新增問題（背景呼叫 Claude AI 生成初步回覆） |
| DELETE | `/api/questions/:id` | 刪除問題（驗證所有權） |
| POST | `/api/reports` | 送出檢舉（防重複 pending 檢舉） |
