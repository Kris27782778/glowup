## 前端實作建議

```
註冊表單欄位建議結構：

1. 學院（dropdown）
   └─ 2. 科系（依學院篩選，dropdown）
      └─ 3. 部別（依科系可選部別，dropdown）
         └─ 4. 年級（依部別顯示對應年級，dropdown）

部別對應年級規則：
  日間部學士班  → 大一 ~ 大四（醫學系 → 大一 ~ 大六）
  進修部學士班  → 大一 ~ 大四
  碩士班        → 碩一 ~ 碩三
  碩士在職專班  → 碩一 ~ 碩三
  博士班        → 博一 ~ 博四以上
  學士後學系    → 大一 ~ 大四
```
