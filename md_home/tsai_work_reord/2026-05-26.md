### 3. Admin 後台大改版（依 glow_admin_dashboard.html 原型）

#### 後端（`backend/routes/admin.js`）

- **`GET /api/admin/questions`** 查詢新增 `answer_count` 欄位（`answers` 表 subquery），供問答管理頁顯示回答數
- **`GET /api/admin/stats`** 補齊本週成長數據（weeklyGrowth）：新增用戶、貼文、問題、收藏、評論、解決問題數、下架貼文數
- 新增 `writeAudit(action, target_type, target_id, detail, admin_note)` 審計日誌 helper，接入所有管理操作
- 新增 **`GET /api/admin/audit?action=&limit=`** 端點供審計日誌頁讀取

#### 前端（`frontend/src/Admin.js`）— 全面升級

**OverviewTab（概覽）**
- 驗證欄位改為顯示已驗證 / 已停權 badge（原為純文字 ✓）
- 新增 `DauChart`：SVG 純手繪折線圖，顯示近 7 日 DAU 走勢（含面積填充、資料標籤）

**UsersTab（會員管理）**
- 新增篩選 chips：全部 / 已驗證 / 未驗證 / 已停權 / 完成膚測
- 表格新增「膚質」欄位（badge 顯示）
- 改用 `filtered` 陣列做客戶端篩選，不影響搜尋邏輯

**QuestionsTab（問答管理）**
- 新增篩選 chips：全部 / 未解決 / 已解決（帶顏色區分）
- 表格新增「回答數」欄位，數值來自後端 `answer_count`

**FunnelTab（轉換漏斗）**
- 改為左右兩欄：左欄保留 Onboarding 漏斗橫條；右欄新增膚質測驗轉換 + Email 驗證統計
- 底部新增用戶行為互動率卡片（2 欄，6 項指標）

**RetentionTab（留存分析）**
- 完整重寫，棄用「即將推出」佔位元素
- 新增 4 個指標卡（Day 1/7/30 留存 + 流失人數，含週環比趨勢文字）
- 新增同期群留存矩陣表格（W1-W4 × Week 0-4，顏色熱圖）
- 新增 `RetentionChart`：SVG 折線圖，顯示近 8 週 Week 0→1 留存趨勢，帶 Y 軸刻度 40%–80%

**HealthTab（系統健康）**
- 服務狀態卡片從 3 個擴充為 6 個（PostgreSQL / API / Email / Meilisearch / AI / 儲存空間），帶 ok/warn 左側邊線顏色
- 新增 `ApiChart`：SVG 折線圖，顯示近 24h API 請求量
- 新增近期錯誤統計卡（4xx/5xx 錯誤率、Email 失敗數、上線時間、平均回應時間）
- 資料庫統計改為 5 欄網格卡片樣式

**AuditTab（審計日誌）**
- 從傳統表格格式改為 log-entry 格式：時間 ＋ 彩色圓形 SVG icon ＋ log-text（粗體主體）＋ log-meta（說明）
- 每種操作類型對應專屬 SVG 圖示（ban / trash / plus / edit / restore / check / x）
- 篩選 chips 保留原有全部 / 用戶 / 產品 / 內容 / 檢舉
